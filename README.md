# Qin Xie — Academic website

Personal academic website: https://paperpig7.github.io/

## Updating the website

- Edit `index.html` to update the biography, working papers, education, and experience.
- Replace `Qin-Xie-CV.pdf` to update the downloadable CV; keep the filename unchanged.
- Replace `qin-xie-portrait.webp` to update the homepage portrait; keep its square crop. The current image is Candidate 2 in its original color, supplied and approved by Qin Xie.
- Edit `styles.css` to change the design.
- Edit `portrait.css` to adjust the portrait's responsive display size.
- Commit changes to `main`. GitHub Pages publishes from the repository root automatically.

This is a static website. No package installation, build command, or server is required. The design and content were exported from the existing personal website, with its latest reviewed edits.
